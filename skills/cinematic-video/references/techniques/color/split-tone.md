# Split Toning

Summary: Highlights and shadows are each assigned a different hue, and the whole frame follows a two-color rule.

## Narrative Function

- Places highlights and shadows in different color families, forming a two-color aesthetic.
- Establishes a visual law governing the whole frame, not a local effect.
- Can convey specific moods, such as a candy-colored night or a dystopian future.

## How It Works

- The toe (shadows) maps to one hue, the shoulder (highlights) to another.
- Set the crossover point in the midtones and calibrate against skin tones.
- Keep the palette limited; the more restrained, the more powerful.

## When to Use

- Use: When highlights and shadows conceptually belong to different color families.
- Avoid: When mixed practical sources already tell the story, or a single tonality is enough.
- Avoid: Using it to replace colored light that actually exists in the scene.

## Film Examples

- *Drive* (2011): Warm highlights over cool shadows in the night sequences.
- *Blade Runner 2049* (2017): Sunlight, smog and interior tones layered along the tone curve.

## Prompt Examples

```text
Split-toned grade: highlights tinted soft magenta-pink while shadows sink into deep violet-blue, a clean two-color world across the whole frame. Midtones cross over gently so skin stays believable; limited palette, applied consistently from shadow to highlight.
```

## Common Mistakes

- Defaulting to teal-orange → specify the two hues explicitly.
- Mistaking colored set lighting for a grading technique → specify which color controls highlights and which controls shadows, and apply consistently across the full tonal range.
