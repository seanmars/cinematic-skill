# Vintage

Summary: Faded dyes, reduced contrast and halos around light sources make the whole frame look like an image archive from the past.

## Narrative Function

- Conveys "this has already happened" through aged chemical characteristics.
- Creates the texture of a time archive, not just a surface effect.

## How It Works

- Combine dye-fade shifts, slight halation on light sources and restrained contrast.
- Add period-appropriate grain as needed.
- Treat time as a chemical process permeating the whole image, not a layer pasted on afterward.

## When to Use

- Use: When the image should be read as an artifact left from the past.
- Avoid: When you only need vintage lens characteristics, only a print curve, or only a single tonality.
- Avoid: Assuming that swapping a lens equals vintage.

## Film Examples

- *The Wonder Years* (1988, TV series): Narrated within a memory frame, using softened, drifted color to express temporal distance.

## Prompt Examples

```text
Vintage film artifact look: faded, slightly drifted color dyes, soft muted contrast and a gentle warm halation glowing around every lamp. Subtle period grain throughout, the whole image aged chemically rather than decorated with scratches or overlays.
```

## Common Mistakes

- Thinking an old lens is enough, or adding only scratches as the whole treatment → dye shifts, low contrast and lamp halos must pervade the whole frame.
- The effect looks like a graphic filter pasted on afterward → treat it with the logic of chemical aging, not a graphic effect.
