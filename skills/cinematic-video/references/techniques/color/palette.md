# Palette

Summary: Sets, costumes, lighting and grading all obey a limited set of hues, forming color rules the audience can learn.

## Narrative Function

- Establishes visual rules that let the audience tell locations, timelines or story states apart.
- Like "design as law": the audience learns the constraint first, so breaking the rule later carries meaning.
- Uses restricted hues to separate storylines, rather than arbitrary multicolor.

## How It Works

- Define consistent color rules across production design, costume, lighting and grading.
- Maintain the rules long enough for the audience to recognize the pattern before deliberately breaking them.
- Remove extraneous hues; every design element supports this limited set.

## When to Use

- Use: When too many colors create visual noise, or multiple storylines need color separation.
- Avoid: When the location needs natural, realistic color.
- Avoid: Faking it with only black and white or grading on an undesigned scene.

## Film Examples

- *Traffic* (2000): Different tonal treatments separate each storyline.
- *Hero* (2002): Different versions of the same event are organized by different dominant colors.

## Prompt Examples

```text
Strictly limited color palette: only muted crimson, ivory and charcoal appear anywhere in the frame, across walls, costumes, props and lighting. Every other hue is removed, so a few chosen colors do all the storytelling work.
```

## Common Mistakes

- Applying split toning to an undesigned scene, with the grade fighting furniture and costumes → control walls, costumes and lighting first, then grade within the constraint.
- Allowed colors not explicitly listed → name the allowed hues explicitly and exclude everything else.
