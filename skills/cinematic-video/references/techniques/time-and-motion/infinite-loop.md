# Infinite Loop

Summary: The last frame joins seamlessly back to the first, so the action always moves forward yet never ends.

## Narrative Function

- Visual approach: the end frame matches the start frame so the join disappears.
- Story approach: an event repeats, but the character's awareness or choices change with each loop.
- These are different tools; don't mix them.

## How It Works

- Match the start and end frames while keeping the action moving forward.
- Story loops need a consistent reset trigger and baseline state, changing only specific actions each round.
- Avoid abrupt transitions or changing the whole scene.

## When to Use

- Use: Actions or situations that shouldn't have an ending, such as a looping walk or a morning that keeps restarting.
- Avoid: When a rewind effect is wanted, or images that are mostly still with only a local area moving.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Boomerang](boomerang.md) | Reverses the same footage; infinite loop keeps one direction |
| [Cinemagraph](../effects/cinemagraph.md) | Background still, only a small area loops |
| [Reverse Motion](reverse-motion.md) | Changes direction rather than creating a seamless loop |

## Film Examples

- *Groundhog Day* (1993): The same morning repeats while the protagonist's reactions gradually change.
- *Run Lola Run* (1998): Multiple attempts with differing choices and outcomes.
- *Edge of Tomorrow* (2014): Repetition drives skill accumulation.

## Prompt Examples

```text
Seamless infinite loop: a paper boat drifts down a winding stream and passes under a small bridge, and the final frame matches the first exactly so the cycle restarts invisibly. Motion always flows forward, no rewind and no visible cut.
```

## Common Mistakes

- Confused with boomerang, with a visible rewind or mismatched join → keep one direction and align the first and last frames precisely.
- Story loop changes too much each round → deliberately control the only variables that change each round.
