# Visual Weight

Summary: Brightness, color, sharpness, faces and motion decide what is seen first in the frame; the pull on attention doesn't equal physical size.

## Narrative Function

- Decides where the audience's eye lands first.
- A small bright object can match a large dark mass; faces draw the eye regardless of size.
- When several elements compete evenly with no hierarchy, the frame loses focus.

## How It Works

- List the competing visual masses and assess each one's "currency": size, brightness, saturation, sharpness, position, faces, motion.
- Pick one winner; darken, desaturate or defocus secondary elements.
- Hard directional light on a small object is an effective way to create a weight difference.

## When to Use

- Use: when several elements in the frame could compete, e.g. a small child in front of a large window, a single colored object in a neutral environment.
- Avoid: lighting every surface evenly.
- Avoid: when the story needs visual ambiguity.

## Film Examples

- *Barry Lyndon* (1975): Hands lit by candlelight outweigh dark coats.
- Desert westerns: Tonal separation keeps tiny riders prominent in vast landscapes.

## Prompt Examples

```text
Visual weight hierarchy: a dark, cavernous study where a single small candle lights an old woman's hands holding a red letter, the only saturated color in the frame. Large furniture and walls fall into deep shadow, so the eye lands on the hands first. 50mm, hard directional light.
```

## Common Mistakes

- Even, polite lighting that treats every object equally, looking like a product catalog → pick one winner and make the other elements yield by lowering brightness, softening, shrinking or desaturating.
