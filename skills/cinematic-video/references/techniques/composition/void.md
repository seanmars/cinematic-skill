# Void

Summary: The environment is erased entirely, isolating the character in pure black or pure white nothingness.

## Narrative Function

- Eliminates place to emphasize isolation and existential alienation.
- Without environment there is no social context, only the subject facing nothingness.
- Not suitable when location details matter.

## How It Works

- Remove all environmental information with black duvetyne, an unlit studio or a featureless white background.
- Light only the character selectively, or make the character a silhouette.
- A long lens helps exclude leftover set elements and prevents light bouncing onto the background.

## When to Use

- Use: psychological isolation, surreal spaces, interrogation scenes, inner mental states.
- Avoid: covering for thin set dressing in scenes where location actually matters.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Negative Space](negative-space.md) | Keeps environmental geography (sky, wall, sea); void erases it entirely |
| [Cameo Lighting](../lighting/cameo-lighting.md) | Creates darkness around the character with lighting, one way to achieve a void |
| [Silhouette](../lighting/silhouette.md) | An outline against a brighter background; can become a void when the background is featureless |

## Film Examples

- *Under the Skin* (2013): A featureless black space makes social geography vanish completely.
- *The Lighthouse* (2019): A weather-isolated environment creates a near-void atmosphere.

## Prompt Examples

```text
Void composition: a lone man stands in pure black nothingness, no floor, walls or horizon visible, lit only by a narrow top light that carves his shoulders and face. Featureless background, long lens, isolated and surreal atmosphere.
```

## Common Mistakes

- Just an underexposed room where baseboards, potted plants or wallpaper are still visible → truly remove the surroundings, or design the "emptiness" as a deliberate composition.
