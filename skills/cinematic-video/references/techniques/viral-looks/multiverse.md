# Multiverse

Summary: The same character appears simultaneously in multiple separate worlds, each version with its own wardrobe and color grade.

## Narrative Function

- Shows parallel lives, expressing choice, regret or comedic self-multiplication.
- Story worlds nested layer within layer, like a "dream within a dream".

## How It Works

- Use architectural compositions that can hold multiple separate scenes: divided spaces, layered rooms, repeating corridors.
- Facial identity stays consistent, while wardrobe and color grade differ.
- Each version must have its own world; they must not blend into each other.

## When to Use

- Use: Plot branches, regret sequences, comedic information overload.
- Avoid: Simple linear scenes; when the worlds can't be named, or a wrong choice has no consequences.

## Film Examples

- *Everything Everywhere All at Once* (2022): Uses wardrobe and palettes to catalog the character's many parallel lives.
- *Doctor Strange* (2016): Builds layered parallel rooms.
- *Inception* (2010): Nested dream levels.
- *Paprika* (2006): Dream and reality spaces pass through each other.

## Prompt Examples

```text
A long mirrored corridor splits into five doorways, each framing the same woman with an identical face: a chef in warm tungsten light, an astronaut in cold blue, a punk singer in magenta neon, an office clerk in flat green fluorescents, a monk in soft gold dawn. Every world is cleanly separated, no blending between them.
```

## Common Mistakes

- Double exposures muddled together → Keep each version clearly separable.
- Doubles look like different people with mixed features → Lock identity; change only wardrobe and grade.
- Worlds have no name or stakes → Give each world a clear identity and a cost for the wrong choice.
