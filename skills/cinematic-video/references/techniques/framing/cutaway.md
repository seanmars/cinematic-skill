# Cutaway

Summary: Briefly leaves the main action to cut to a related detail, onlooker or environment, then returns to the main line.

## Narrative Function

- Builds anticipation, shows others' reactions, implies the passage of time.
- Lets the surroundings comment on the main action or add context.
- It is not just for covering an edit point.

## How It Works

- Pick a detail that "plausibly exists at that moment".
- Lighting and ambient sound must match the main scene.
- When returning to the main line, pick up at a later stage of the action, not the frame where it stopped.

## When to Use

- Use: Hiding continuity problems, showing time passing, providing context or giving tension a brief breather.
- Avoid: Shooting what's in the actor's hands (that is an insert).
- Avoid: Creating temporally impossible geography, or rewinding the action on return.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Insert](insert.md) | Stays within the action on a story-critical object |
| [Reaction Shot](reaction-shot.md) | Focuses on a person's reaction; a cutaway need not be a person |
| [Cut-ins](cut-ins.md) | Tightens onto something already visible in the master, still in the same space |

## Film Examples

- *Dancer in the Dark* (2000): Wider or closer frames bracket the in-car conversation.
- *Jurassic Park* (1993): Environmental details and onlookers are intercut to heighten the approaching threat.
- *Hot Fuzz* (2007): Cutaways serve as both gags and structural glue.

## Prompt Examples

```text
Cutaway from a tense poker game to the rain-streaked window of the same room, where a neon sign outside flickers and a clock above it reads 3:12 a.m. Same cool practical lighting and muffled rain sound as the main scene.
```

## Common Mistakes

- Confusing it with an insert, or cutting to any random pretty detail → Genuinely leave the main beat and choose a temporally plausible image.
- Rewinding the action on return → Honestly pick up at a point where the action has moved forward.
