# Cross-Cutting

Summary: Cut back and forth between two or more locations or storylines, implying they happen simultaneously and are converging.

## Narrative Function

- Weaves parallel events together to build tension (e.g. a ritual and a crime happening at the same time).
- The core drive is "simultaneity": two independent timelines racing toward each other.

## How It Works

- Each line needs clear geography, readable time markers and compatible details.
- Alternate between them, gradually shortening each segment to accelerate tension.
- Sound can bridge both lines, adding cohesion.

## When to Use

- Use: a raid and a doorbell, competing escapes, layered dreams affecting each other.
- Avoid: using it to dump unused footage from the same scene.
- Avoid: when both actions need to be seen at once; use Split Screen instead.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Montage](montage.md) | Compresses time through collision; cross-cutting keeps both lines' clocks running |
| [Split Screen](split-screen.md) | Shows both lines at once instead of alternating |
| [Smash Cut](smash-cut.md) | A single contrast cut, not sustained weaving |

## Film Examples

- *The Godfather* (1972): a baptism intercut with the assassination of rivals.
- *The Silence of the Lambs* (1991): an FBI raid alternates with the doorbell at the killer's house, finally revealing a geographic misdirect.
- *Inception* (2010): layered dreams pressure one another through alternation.

## Prompt Examples

```text
Cross-cutting sequence: alternate between a bride walking down a candlelit church aisle and a getaway car speeding through rain-soaked streets toward the church. Each cut gets shorter as both lines converge; two distinct locations, never blended in one frame.
```

## Common Mistakes

- The second line has no sense of time passing → establish two independent spaces and implied simultaneity.
- Confused with montage or split screen → keep geography clear (or deliberately misleading) and keep alternating.
