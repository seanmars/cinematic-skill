# Dissolve

Summary: The outgoing shot gradually fades out while the next fades in, the two images briefly overlapping for a soft transition.

## Narrative Function

- Conveys the passage of time, memory or a gentle scene ending.
- Replaces an abrupt hard cut with a soft handoff.
- Duration and sound determine whether it represents seconds or years.

## How It Works

- The outgoing shot's opacity gradually decreases while the incoming shot's increases.
- Both images are visible during the transition, which lasts from about 12 frames to several seconds.
- Align compositions where possible so the overlap reads more easily.

## When to Use

- Use: montages, flashbacks, moments that need a gentle transition.
- Avoid: moments that need impact.
- Avoid: cuts that need a crisp graphic correspondence.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Fade](fade.md) | Transitions to a solid color; a dissolve has image content throughout |
| [Double Exposure](../effects/double-exposure.md) | Overlays to create layered meaning; a dissolve is only a handoff |
| [Match Cut](match-cut.md) | Links through visual rhyme with a hard cut |

## Film Examples

- *Citizen Kane* (1941): dissolves mark the passage of time across life stages.
- *Apocalypse Now* (1979): helicopters, a hotel ceiling fan and jungle imagery dissolve in layers, synced with sound.
- *The 39 Steps* (1935): a scream turns into a train whistle, bridging with sound.

## Prompt Examples

```text
Slow cross-dissolve over two seconds: a young girl on a swing in a summer garden gradually fades while the same garden in winter, empty swing, fades in. Both images visible as ghosts at the midpoint, only opacity changes, no warping.
```

## Common Mistakes

- Black appears in the middle, turning it into a fade → keep both images continuously visible.
- Shapes warp into a morph → adjust only opacity; both images must be clearly readable at the midpoint.
