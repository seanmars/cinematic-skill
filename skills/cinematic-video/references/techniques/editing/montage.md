# Montage

Summary: Create meaning through the order of a series of different shots, so inference comes from the collision between shots rather than any single image.

## Narrative Function

- Compresses time or builds an argument through juxtaposition, condensing months into minutes.
- Every cut conveys an inference; meaning arises only when two images combine.

## How It Works

- First decide the inference the audience should draw, then choose images with clear relationships to each other.
- Use similar geometry for analogy, and progressive details to show training or progress.
- Treat shot length as beat control: shorten gradually toward the climax, or linger at the close.

## When to Use

- Use: training sequences, passage of time, thematic visual arguments.
- Avoid: when continuous action needs to be clearly laid out.
- Avoid: merely cutting a few seconds out of the same setup (that is a Jump Cut).

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Cross-Cutting](cross-cut.md) | Weaves simultaneous actions; in a montage each shot is a unit of argument |
| [Jump Cut](jump-cut.md) | Cuts time out of the same setup; a montage collides entirely different images |
| [Match Cut](match-cut.md) | Two images express the same concept through visual similarity |

## Film Examples

- *Strike* (1925): workers juxtaposed with slaughterhouse images.
- *Rocky* (1976): training compressed through progressive labor.
- *Up* (2009): a lifetime of marriage condensed into a few moments.
- *Citizen Kane* (1941): the breakfast table sequence shows a marriage gradually falling apart.

## Prompt Examples

```text
Montage of six distinct shots with shrinking durations: a boxer's taped hands, a pre-dawn run up empty stairs, a sweat-soaked jump rope, a punching bag swinging harder, a mirror showing a leaner face, arms raised at the summit. Hard cuts, no morphing, order builds the sense of progress.
```

## Common Mistakes

- Fast cutting with no argument, or calling a single moving shot a montage → establish the inference and time span first.
- Shots morph into each other → choose independent shots and let their order create meaning.
