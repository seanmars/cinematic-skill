# Flash Cut

Summary: Insert a few frames of a different image into an ongoing scene, then immediately hard cut back to the present.

## Narrative Function

- Shows thoughts, memories, premonitions or trauma intruding on the present.
- Because it is so short, the insert never becomes a new scene; it reads as a psychological leak or subconscious threat.

## How It Works

- Stay on the current shot and insert 1-8 frames of a strongly contrasting image (often closer or from another time).
- Hard cut back to the original image, with no dissolve.
- The abruptness is the grammatical core of the technique.

## When to Use

- Use: depicting psychological intrusion or a threat that is hard to identify.
- Avoid: using it as trailer-style decoration.
- Avoid: when the inserted image needs to become a new scene.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Crash Cut](crash-cut.md) | Stays on the new image and does not return to the original scene |
| [Light Flash](../effects/light-flash.md) | Just a white flash, not a different in-story image |
| [Jump Cut](jump-cut.md) | Jumps time within similar framing, with no foreign image |
| [Smash Cut](smash-cut.md) | Treats the contrasting image as the new present |

## Film Examples

- *The Ring* (2002): sneaked-in frames create a sense of "contamination".
- *Natural Born Killers* (1994): a barrage of disruptive images erupts like a nervous system.
- *Arrival* (2016): images first taken as memories are later repositioned in time.

## Prompt Examples

```text
Flash cut: a woman calmly stirs coffee in a sunlit kitchen; for four frames the image hard cuts to a close-up of a burning car at night, then instantly back to the kitchen as if nothing happened. No dissolve, extreme contrast between the present and the intrusion.
```

## Common Mistakes

- Only a white flash with no second image → insert real in-story footage.
- No return to the original scene after the insert → specify a countable number of frames and hard cut back to the original image.
