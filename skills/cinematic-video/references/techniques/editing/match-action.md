# Match on Action

Summary: An action starts in one shot and finishes in the next, hiding the cut in the motion so the audience follows the action without noticing the change.

## Narrative Function

- Uses motion as a bridge to hide the cut, preserving the continuity of the action.
- Makes changes in shot size or angle smooth rather than jarring.

## How It Works

- Match action speed, hand position, object placement and body orientation across both shots.
- Cut as the action accelerates or midway through, not after it completes.
- Confirm that screen direction and sound match on both sides of the cut.

## When to Use

- Use: when one action needs a change of shot size or angle (opening a door, throwing a punch, sitting down, pouring water).
- Avoid: when jumping time or changing location.
- Avoid: when the action itself is not continuous.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Match Cut](match-cut.md) | Links two different images thematically; match on action stays within the same event |
| [Axial Cut](axial-cut.md) | Changes distance along the same axis, with no need for action as a bridge |
| [Graphic Match](graphic-match.md) | Crosses time through shape, not continuous action |
| [Invisible Cut](invisible-cut.md) | Hides the cut with occlusion or blur rather than visible action |

## Film Examples

- *Neighbors* (1920): Buster Keaton's movement across a courtyard continues between different viewpoints.
- *The Matrix* (1999): fight moves connect across different shot sizes and angles.

## Prompt Examples

```text
Match on action: wide shot of a woman reaching for a door handle with her right hand, cut mid-gesture to a close-up from the same side as the same right hand turns the handle. Speed, hand position and screen direction stay continuous across the cut.
```

## Common Mistakes

- The close-up switches to the other hand → keep the same hand throughout.
- Walking direction reverses after the cut → maintain consistent screen direction.
- The action completes twice → cut mid-action, not after it lands.
