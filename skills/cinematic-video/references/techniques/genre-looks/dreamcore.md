# Dreamcore

Summary: Deserted interiors, soft childhood-era lighting that feels faulty and low contrast, like being trapped in a memory that cannot come into focus.

## Narrative Function

- Creates unsettling nostalgia through empty domestic spaces and malfunctioning childhood lighting.
- Fear comes from unresolved space, not jump scares.
- The audience feels trapped in a memory that will not become clear.

## How It Works

- 24-35mm wide angle, eye level, mostly static shots.
- Soft sources: fluorescents, cheap tungsten bulbs, blown-out windows.
- Muted 1990s suburban color or sickly pool teal; deliberately low contrast, milky blacks; empty mid-ground, very few people.

## When to Use

- Use: Presenting "nostalgia that has lost its sense of safety" in enclosed interiors.
- Avoid: Captioned JPEG horror (that is Weirdcore).
- Avoid: Perception-warping effects, or daylight miracles in realist scenes.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Weirdcore](weirdcore.md) | Degraded digital, captioned; dreamcore is analog softness |
| [Altered State](../effects/altered-state.md) | The image is actually distorted; dreamcore keeps spatial continuity |

## Film Examples

- *Synecdoche, New York* (2008): Duplicated rooms form a warehouse-like memory space.
- Internet Backrooms lore: Centered on liminal interior spaces.

## Prompt Examples

```text
Dreamcore interior: an empty 1990s suburban hallway with beige carpet and a single child's toy on the floor, lit by a buzzing overhead fluorescent and a blown-out window at the far end. Static 28mm eye-level frame, very low contrast with milky blacks, soft muted colors, no people, clean resolution.
```

## Common Mistakes

- Adding JPEG artifacts, cutout graphics or psychedelic smears → Maintain resolution quality.
- Key light too hard, space filled up → Soften the key, keep the hallway empty, and use lighting close to the childhood era.
