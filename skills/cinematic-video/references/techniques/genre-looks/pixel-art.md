# Pixel Art

Summary: The entire world is built from visible square pixels and a low-resolution grid, with a limited palette and coarse sampling.

## Narrative Function

- Establishes a discrete, grid-based world aesthetic.
- Must serve the story's needs; do not force it in just for visual novelty.

## How It Works

- Lighting, palette, lens and blocking together form a consistent pixel style.
- Treat each shot as a state transition: define a starting state, execute one deliberate change, and leave an end frame that can carry forward.
- Lead with character action, then layer camera and lighting choices on top.

## When to Use

- Use: When the visual world truly consists of blocky elements.
- Avoid: Using it to artificially raise production value.
- Avoid: When the point is actually playable game mechanics; use Video Game instead.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Video Game](video-game.md) | Emphasizes playability; pixel art emphasizes grid-based construction |

## Film Examples

- Reference the visual language adjacent to indie games and *Wreck-It Ralph* (2012), borrowing compositional relationships rather than copying frames.

## Prompt Examples

```text
16-bit pixel art scene: a small knight walks right across a moonlit castle rampart, rendered in chunky visible pixels with a limited 32-color palette and hard dithered shading. Side-on orthographic view, one slow horizontal camera scroll following him, crisp pixel edges with no smoothing or blur.
```

## Common Mistakes

- Confusing it with a Video Game treatment → Stick to the grid aesthetic; if the story needs interactivity, use Video Game instead.
- Pixel edges are smoothed → Emphasize coarse sampling and a limited palette, with at most one motivated camera move per segment.
