# Weirdcore

Summary: The familiar is "miscoded": ultra-low resolution, JPEG compression artifacts, awkwardly cropped faces and default-font captions, like an eerie early-internet meme.

## Narrative Function

- Creates early-internet dread that feels like both a joke and a threat.
- Deliberately breaks familiarity (cropped-off faces, default fonts, JPEG artifacts) so the audience feels "this shouldn't look like this."

## How It Works

- Drop resolution below 240p, adding JPEG compression artifacts and chromatic aberration.
- Crop subjects clumsily, especially faces.
- Use on-camera flash or analog-style underexposed shadows; add captions in basic fonts; the palette is Windows-era interiors, flash-lit skin and dead blacks.

## When to Use

- Use: When familiar objects must look misrendered or corrupted.
- Avoid: Soft memory spaces (use Dreamcore), psychedelic distortion.
- Avoid: Polished nostalgia styles.

## Film Examples

- *Skinamarink* (2022): Dark analog rooms and unseen faces, close to internet horror.

## Prompt Examples

```text
Weirdcore image: a low-resolution 240p photo of a child's bedroom lit by harsh on-camera flash, heavy JPEG blocking and color fringing, a smiling face awkwardly cropped at the frame edge. A caption in plain default font reads a cheerful but unsettling line; crushed blacks, early-internet feel.
```

## Common Mistakes

- Drifting into Dreamcore softness or Vaporwave polish → Heavily compress the file quality.
- Composition too normal → Keep the wrong crops, add cheap flash and captions, and sustain the joke-as-threat tension.
