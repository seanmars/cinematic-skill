# Anthropomorphic

Summary: Shoot an object or animal as an actor with intent, using eyeline, blocking and posture to bring it "to life."

## Narrative Function

- Gives non-human characters human-like agency and presence.
- Implies intent through blocking, eyeline and movement; facial features are not required.
- Differs from Object POV (camera inside the object) and Tableau (static composition).

## How It Works

- Give the object an eyeline height that matches human proportions.
- Cover it with the same shot sizes as a human actor: wide, medium, close-up.
- Create gestures with puppetry, wire rigs or animation.
- Have other characters interact with it as a scene partner.

## When to Use

- Use: When a non-human character needs to show intent and presence in a scene.
- Avoid: Simple product insert shots or still-life arrangements.
- Avoid: A true POV looking out from inside the object.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Object POV](../camera-angles/object-pov.md) | Camera sits inside the object |
| [Tableau](../composition/tableau.md) | Freezes people into a composed picture |
| [Macro](../lenses/macro.md) | Isolates texture detail, no eyeline |

## Film Examples

- *The Red Balloon* (1956): The balloon waits and reacts like a companion.
- *WALL-E* (2008): The robot has no real face, yet human-like gestures and eyeline.

## Prompt Examples

```text
An old desk lamp acts as a shy character in a cluttered attic: its shade tilts at human eye height toward a little girl, hesitates, then slowly bows as if embarrassed. Cover it with a medium two-shot and a reaction close-up just like a human actor, while the girl answers it as a scene partner.
```

## Common Mistakes

- Mounting the camera inside the object, or treating it as a static prop → give it a clear eyeline and appropriate scale.
- Missing reaction shots → shoot reaction coverage for it and have other characters treat it as a collaborator.
