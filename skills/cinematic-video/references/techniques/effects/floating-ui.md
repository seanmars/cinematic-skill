# Floating UI (HUD Overlay)

Summary: Readable interface panels float in 3D space around the character, producing parallax as the camera moves.

## Narrative Function

- Makes data and interfaces tangible, letting characters interact with information as if handling physical objects.
- Shows a character's expertise, a high-tech environment or internal information processing.

## How It Works

- Composite multiple interface planes in front of the subject, each with its own vanishing point and depth (from a few centimeters to several meters from the face).
- When the camera moves, the panels must produce parallax against the background.
- Keep text readable; panels can have a slight self-illumination but must not replace the scene's key light.

## When to Use

- Use: Pilots, surgeons or detectives reading or manipulating data in midair.
- Avoid: Adding decorative graphics to portraits with no data context.
- Avoid: Using it as a station logo or lower-third pinned to the frame edge.

## Film Examples

- *Minority Report* (2002): Characters drag and manipulate data planes in midair with gestures.
- *Iron Man* (2008): A 3D annotated interface inside the helmet surrounds the hero's face.

## Prompt Examples

```text
A pilot in a dim cockpit reaches toward translucent holographic panels hovering at different depths in front of her face, each showing legible flight data. As the camera slowly arcs, the panels shift with clear parallax against the background, while the cabin's practical lighting still shapes her face.
```

## Common Mistakes

- Text stuck to the frame edges like 2D overlay titles → build real depth and let panels produce parallax with the camera.
- Light just crawls over surfaces with no sense of floating planes → panels must be independent spatial planes, and keep the scene's original key light.
