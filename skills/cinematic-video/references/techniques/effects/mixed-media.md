# Mixed Media

Summary: Live action, illustration, text and data imagery collide on the same plane, with visible boundaries rather than blending.

## Narrative Function

- Use when news, memory and bodily experience can't be explained in a single medium.
- Deliberately avoids the false unity of a single camera, letting different sources clash.

## How It Works

- Layer different capture methods, keeping visible edges (torn edges, cutouts, direct splices).
- Lighting need not match across media; the mismatch proves the sources differ.
- Keep one recognizable subject as the focal point of the collision.

## When to Use

- Use: When documents, broadcast footage and people must combine in one frame.
- Avoid: When the scene needs the unified realism of a single camera.
- Avoid: When you're only adding type over color-graded live action.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Collage](collage.md) | Layers still images and textures; mixed media emphasizes different capture modes |
| [Typography](typography.md) | Treats only text as an object; mixed media involves a collision of multiple sources |

## Film Examples

- *Natural Born Killers* (1994): TV footage, film stock and graphic inserts clash.
- *Everything Everywhere All at Once* (2022): Illustration, stock footage and live action coexist on one plane.

## Prompt Examples

```text
A live-action close-up of a young man is torn at the edges and layered over a grainy VHS news broadcast, while hand-drawn ink scribbles and bold newspaper headlines cut across the frame. Each layer keeps its own texture and lighting, with the man's face as the clear focal point.
```

## Common Mistakes

- A single overall texture with only added type or plain collage → use at least two capture modes and keep visible edges.
- No visual focal point → keep one subject clearly readable.
