# Duplication

Summary: The same actor appears in frame as two or more solid people at once, interacting with each other.

## Narrative Function

- Expresses split identity: twins, meeting oneself, parallel versions of oneself.
- Requires visible physical interaction: shared shadows, eye contact, handling objects together.
- Unsuited to ghostly presences or gradual transitions between forms.

## How It Works

- Lock off the camera, or use motion control to repeat the exact same move.
- Shoot each performance separately under consistent lighting.
- Composite with split mattes and tracked mattes; plan body overlaps and contact points during the shoot or handle them in post.

## When to Use

- Use: When a single actor must share a room as two physically present characters.
- Avoid: Flashback sequences, spirit imagery or gradual transformations.
- Works only when the two bodies can truly interact, occlude each other and cast shared shadows.

## Compared With Similar Techniques

| Technique | Difference |
| --- | --- |
| [Double Exposure](double-exposure.md) | Translucent layering, not solid bodies |
| [Split Screen](../editing/split-screen.md) | A visible dividing line between two simultaneous scenes |
| [Morph](match-morph.md) | Gradual transformation, not two forms coexisting |

## Film Examples

- *The Parent Trap* (1961 / 1998): Twin sisters play opposite each other in the same composition.
- *Adaptation* (2002): Two versions of the same character talk to each other.
- *Enemy* (2013): The protagonist keeps encountering another version of himself.
- *The Social Network* (2010): Motion control used to present the Winklevoss twins.

## Prompt Examples

```text
Locked-off kitchen scene with one actor playing twin brothers: one in a gray suit leans on the counter while the other, in a stained apron, hands him a coffee mug. Both bodies are solid and opaque, the mug passes cleanly between their hands, and both cast matching shadows under the same window light. No ghostly transparency, no visible split line.
```

## Common Mistakes

- Inconsistent lighting, obvious seams → use identical locked-off plates and match key light and grain.
- Turning into translucent layering → bodies must be opaque, with planned occlusion.
- Casting two different actors → use the same actor, distinguished by posture and costume, and handle shared shadows.
