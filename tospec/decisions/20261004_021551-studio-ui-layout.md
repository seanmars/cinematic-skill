# studio UI: 剪輯軟體式版面、深色中性主題、zh-TW/en、React + Tailwind + shadcn/ui

## Status

- proposed
- Date: 20261004_021551

## Context

studio 要顯示專案、階段、gate、鏡頭、預覽和音效.每顆鏡頭都有時長,SFX cue 也有時間點.不過不是每個 gate 都跟時間軸有關: Intake 是表單,Treatments 是 3 張方案卡,Gauntlet 是 critic 報告.

使用者自己用繁體中文,但 skill 是公開散佈的.參考的 open-slide 用 React + Tailwind + shadcn/ui (`packages/core/src/app/components/ui` 由 shadcn 產生),並有 locale 系統 (`src/locale/en.ts`、`zh-tw.ts`、`zh-cn.ts`、`ja.ts`).

## Decision

- **剪輯軟體式版面**:
  - 左側: 專案列表和階段.
  - 中間上方: `render(t)` 預覽.
  - 中間下方: 時間軸,鏡頭依時長排列,並把 `audio/plan.json` 的 SFX cue 畫成音軌.
  - 右側: inspector,編輯選中的鏡頭,並提供核准和修改按鈕.
  - 中間區域依 gate 切換: Intake 顯示表單,Treatments 顯示方案卡,Gauntlet 顯示報告;分鏡存在之後才出現時間軸.
- **深色中性主題**: 這是影片工具的慣例.中性的深色背景不會干擾對預覽顏色的判斷,強調色只用在狀態和操作上.
- **介面語言**: 一開始就把字串抽成 locale 檔,支援繁體中文和英文.
- **前端技術**: React + Tailwind + shadcn/ui,跟 open-slide 一樣,可以直接參考它的元件和做法.

選擇理由: 鏡頭有時長,所以時間軸是最自然的呈現方式;深色中性主題能讓顏色判斷不失真;一開始就抽 locale 成本很低,之後再補會很痛.

## Impact

- studio 前端: 版面骨架、各 gate 的中間區域、時間軸、inspector、locale 檔.
- `studio/package.json`: React、Tailwind、shadcn/ui 相關依賴.

## Alternatives

- **卡片網格式 (階段 stepper + 鏡頭卡片)**: 像分鏡板,一眼看到整體,但看不出時長比例.不採用.
- **文件流式 (一頁由上而下)**: 實作容易,但專案一大就要一直捲動.不採用.
- **跟隨系統或淺色主題**: 淺色背景會讓預覽看起來偏暗,也不利於判斷畫面顏色.不採用.
- **只有繁體中文或只有英文**: 一個讓公開使用者看不懂,一個讓作者自己用起來不順.不採用.
- **輕量框架 (Preact 或 Svelte)**: 依賴比較小,但不能直接參考 open-slide,元件也要自己做.不採用.
